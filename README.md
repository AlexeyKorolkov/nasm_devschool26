# Репозиторий курса "Архитектура цифровых вычислительных устройств"

## Настройка окружения

### Docker

Окружение для работы с ассемблером NASM в среде ОС Linux (Ubuntu) реализовано в разработческом контейнере (devcontainer). Для запуска devcontainer необходимо:

- IDE. Рекомендуется VS Code

- Установить Docker. Инструкция - на [официальном сайте](https://docs.docker.com/engine/install/).

- Обязательно Docker перевести в ***rootless-режим***. Это необходимо для того, чтобы в томе, монтируемом к контейнеру, создавались файлы, принадлежащие локальному пользователю, а не `root`. Инструкция - на [официальном сайте](https://docs.docker.com/engine/security/rootless/).

### Особенности Mac на Apple Silicon

Процессоры этого семейства имеют архитектуру ARM. Ввиду того, что на курсе изучается архитектура х86, то понадобятся инструменты эмуляции машинных команд целевой архитектуры. А именно - Rosetta2 - транслятор машинных команд х86 в машинные команды ARM.

Установка:

```zsh
softwareupdate --install-rosetta --agree-to-license
```

Обратите внимание, что эмуляция х86-64 в реальном времени может вызвать небольшие проблемы с производительностью контейнера. Однако, это не должно создавать критичных проблем при выполнении учебных задач.

## Запуск Devcontainer

### Подготовка

При первом запуске важно выбрать нужный для вас Dockerfile - файл описания контейнера, а также указать дополнительные параметры запуска. Для этого вам нужно открыть [файл конфигурации devcontainer](.devcontainer/devcontainer.json) и его отредактировать под вашу платформу. Все подсказки указаны в русскоязычных комментариях. Пушить эти изменения в репозиторий при сдаче ДЗ ***не нужно***.

### Сборка и подключение

Далее нужно запустить сборку контейнера и осуществить подключение к нему:

1. В левом нижнем углу находим кнопку "Открыть удалённое окно"
2. В появившемся сверху выпадающем списке выбираем "Повторно открыть в контейнере"
3. Ждём сборку
4. Если сборка прошла корректно, то VS Code переоткроется в среде контейнера. В разделе "Проводник" должны отобразиться файлы проекта. На кнопке удалённого подключения должна быть надпись с названием контейнера и контекстом Docker: `nasm_devschool26 @ rootless`
5. Профит
