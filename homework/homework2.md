# Домашнее задание 2

## Задача 1

1. Прочитать в имеющейся литературе о системных вызовах (Столяров, Керриск (главы 3-5 полностью включительно)).
2. Воспроизвести пример "hello world" из презентации.
3. Найти недостатки примера, внести исправления.

## Задача 2

1. Вывести строку "Hello world" в текстовый файл. Использовать соответствующие системные вызовы. 
2. На случай возникновения ошибок подготовить соответствующие сообщения для вывода на консоль. Сообщения об ошибках сделать красным шрифтом (используйте escape-последовательности для раскрашивания, информацию см. [здесь](https://habr.com/ru/companies/macloud/articles/558316/))

**Формат сдачи ДЗ не меняется**

***Использование LLM запрещено***

## Рекомендации:

- Реорганизуйте репозиторий так, чтобы файлы задач находились в отдельных папках. Пример:

```
nasm_devschool26
...
|---IvanPetrov
    |---homework1
        |---nothing.asm
        |---nothing.lst
        |---nothing.log
    |---homework2
        |---task1.asm
        |---task2.asm
```
- Для лучшего понимания лучше комментровать каждую строку.
- При необходимости производите отладку при помощи `strace`. Также при необходимости можно использовать другие инструменты бинарного анализа. Пушить артефакты отладки (листинги, логи) не нужно.
- Для сборки можете использовать makefile из корня репозитория
