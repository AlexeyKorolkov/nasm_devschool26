# Домашнее задание 1

## Что требуется

1. Ознакомиться с утилитой strace. [Инфа здесь](https://habr.com/ru/companies/badoo/articles/493856/).
2. Воспроизвести пример из класса (см. последний слайд презентации).
3. Запустить пример под `strace`, сохранить лог в файл `strace.log`.
4. Собрать с получением листинга машинных команд, листинг сохранить в `nothing.lst`.
5. Запушить код, лог и листинг в отдельную ветку.
6. Ознакомиться с основными машинными командами x86 - см. книги Столярова и Зубкова.

## Формат сдачи ДЗ:
- В своей ветке создаёте папку под своими именем и фамилией, например: IvanPetrov.
- Файлы проекта располагаете в своей папке. В корень проекта добавлять ничего не нужно.
- По окончании работы создаёте pull request на слияние вашей ветки с `master`. Бинарные и объектные файлы пушить **не нужно**.
- При выявлении замечаний, они будут записаны в комментариях к вашему PR.
- Работа считается принятой, если PR принят.
